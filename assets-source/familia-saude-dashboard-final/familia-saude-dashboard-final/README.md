# Família Saúde — Dashboard Web Final

Pacote final das telas web administrativas do Família Saúde. A tela inicial anterior com a seção de Notificações foi removida do escopo conforme solicitado.

## Telas incluídas

1. Login web
2. Visão geral revisada
3. Usuários
4. Assinaturas
5. Medicamentos
6. Médicos
7. Relatórios
8. Configurações

## Estrutura

- `telas-web/`: oito telas finais em PNG, organizadas por módulo.
- `design-system/DESIGN-SYSTEM.md`: identidade visual, tokens, layout, tipografia, componentes e regras de uso.
- `elementos-e-icones/`: inventário dos elementos e ícones presentes nas telas.
- `documentacao/inventario.csv`: nomes, dimensões, tamanhos e descrição dos arquivos.
- `documentacao/NOTA-SOBRE-ASSETS.md`: explicação sobre assets achatados e limitações para edição individual.

## Formato

As telas estão em formato desktop 16:9, com 2560 × 1440 px.
