# Inventário de elementos e ícones

## Elementos presentes nas telas

- Sidebar administrativa;
- Logomarca/mark do Família Saúde;
- Cabeçalho de página;
- Perfil do administrador;
- Cartões KPI;
- Barras de busca;
- Filtros e selects;
- Botões primários e secundários;
- Tabelas de dados;
- Pills de status;
- Gráficos de linha, barras e progresso;
- Cards de resumo;
- Paginação;
- Avatares;
- Ícones de busca, filtro, exportação, configuração, usuários, assinatura, medicamento, médico, relatório, edição e visualização.

## Observação sobre assets editáveis

As telas disponíveis neste pacote são PNGs finais achatados em 2560 × 1440 px. Os ícones, textos, gráficos, cartões e ilustrações aparecem incorporados na composição e não foram fornecidos na conversa como arquivos SVG, PNG individuais, fonte de ícones ou componentes separados.

Por isso, esta pasta contém o inventário conceitual dos elementos, mas não afirma que existam camadas editáveis individuais. Para implementação, o agente de desenvolvimento deverá recriar os componentes usando o Design System, uma biblioteca de ícones consistente e dados reais.
