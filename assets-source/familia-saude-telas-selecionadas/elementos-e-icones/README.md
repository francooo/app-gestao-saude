# Elementos e ícones

Os elementos visuais e ícones estão incorporados nas telas PNG da pasta `../telas/`. Este diretório não contém camadas separadas porque as imagens entregues nesta conversa são composições finais achatadas.

A identidade visual observada nas telas inclui:

- Verde-sálvia e verde-musgo;
- Creme, caramelo e mostarda;
- Cartões com cantos arredondados;
- Ícones lineares;
- Ilustrações botânicas;
- Avatares e cartões de medicamentos;
- Elementos de WhatsApp, IA, câmera, notificações, médicos e assistente.

Os ícones não devem ser considerados arquivos independentes editáveis neste pacote.
