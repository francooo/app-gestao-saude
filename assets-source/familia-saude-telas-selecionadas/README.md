# Família Saúde — telas selecionadas

Este pacote reúne as 19 telas finais selecionadas durante a criação do aplicativo Família Saúde.

## Conteúdo

- `telas/`: imagens PNG completas, em formato vertical mobile.
- `elementos-e-icones/`: documentação sobre os elementos visuais disponíveis.
- `documentacao/inventario.csv`: inventário técnico com dimensões e tamanhos dos arquivos.

## Observação importante sobre elementos e ícones

As telas foram geradas e disponibilizadas como imagens finais achatadas (PNG). Portanto, os ícones, cartões, textos, ilustrações e demais elementos que aparecem dentro de cada tela estão incorporados nos próprios arquivos de imagem e não existem neste pacote como camadas editáveis ou arquivos SVG/PNG individuais.

Para reutilizar um elemento isoladamente em desenvolvimento, será necessário redesenhá-lo ou extraí-lo com um processo de vetorização/recorte, pois a fonte original em camadas não foi fornecida nesta conversa.

## Formato

As imagens estão em proporção mobile vertical, normalmente com 1440 × 2560 px.
